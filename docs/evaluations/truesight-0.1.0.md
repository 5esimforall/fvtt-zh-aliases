# Truesight 0.1.0 接线验证

日期：2026-11-05。配套版本：Slow Insert 0.6.8、CPR 中文适配 0.3.1、GPS 中文适配 0.3.1。

## 变更范围

聚类、来源书目与名称 core 合并为 `真实视觉 · Truesight`，ID 为 `truesight`。聚类算法维持原规则版本 1。运行时代码只有基座计算与保存审核；两个名称适配通过 `api.names` 接入，Slow Insert 从公开 `api-v1.mjs` 获取关系及来源解析。

本次采用按世界、用户、浏览器客户端隔离的审核；没有实现 GM 世界级分发。旧客户端快照经过明确预览迁入，原值保留。无需变更 Foundry 世界数据。

## 自动测试

- Slow Insert：155 项通过，包含生产消费者共用真实公共 API 的集成测试。覆盖首选／搜索不改变身份、打开与拖放原对象、失效和权限过滤；额外检查 QI 遗留结果不会作为独立行或筛选选项重新出现。
- Truesight 与两个名称适配：60 项通过，无跳过。包含两个本机源码回放；其余测试使用合成索引和内存状态。
- 基座覆盖未就绪、未审核、失败区分，应用／撤销、单层持久化失败、过期预览、权限变化、显式旧快照迁移及新增成员不入组；原始文档和搜索包装不会进入公共 DTO。
- 名称适配覆盖目录变更重建、CPR 仅撤回自己仍持有的映射、停止或过期异步构建不回写、可选汉化包缺席时保留独立名称证据。
- 两个工作区的完整语法检查通过。

本机只读回放环境：CPR 1.5.49、GPS 2.1.44、简体中文 Babele 汉化包 1.0.202。回放使用实际安装源码中的查找函数和译表，以夹具提供合集及文档；不连接世界，不执行自动化应用或宏。
